┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : PRÉPARATION (5 minutes)                                            │
└──────────────────────────────────────────────────────────────────────────────┘

  ✅ Créez un compte GitHub         → https://github.com/signup
  ✅ Créez un compte Vercel         → https://vercel.com (gratuit)
  ✅ Installez Node.js (optionnel)  → https://nodejs.org

┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : CRÉER LE DÉPÔT GITHUB (2 minutes)                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Allez sur GitHub → New Repository
  2. Nommez-le: "gaudi-walking-app"
  3. Cliquez "Create Repository"

  ┌─────────────────────────────────────┐
  │ gaudi-walking-app                   │
  │                                     │
  │ [Description: My Gaudí Walking App] │
  │                                     │
  │ ☑️ Public                          │
  │ ☑️ Initialize with README           │
  │                                     │
  │        [Create Repository]          │
  └─────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : UPLOADER LES FICHIERS (3 minutes)                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  Structure finale de votre repo :

    gaudi-walking-app/
    ├── app/
    │   ├── page.js                 ← Copier le fichier gaudi-walking-app.jsx
    │   ├── layout.js               ← Voir CONFIGURATION_FILES.txt
    │   └── globals.css             ← Voir CONFIGURATION_FILES.txt
    ├── .gitignore                  ← Voir CONFIGURATION_FILES.txt
    ├── package.json                ← Copier le fichier fourni
    ├── next.config.js              ← Voir CONFIGURATION_FILES.txt
    ├── tailwind.config.js          ← Voir CONFIGURATION_FILES.txt
    ├── postcss.config.js           ← Voir CONFIGURATION_FILES.txt
    ├── README.md                   ← Copier le fichier fourni
    └── vercel.json                 ← Voir CONFIGURATION_FILES.txt

  ⚠️ IMPORTANT: Le fichier "page.js" est LE fichier crucial !
  C'est le composant React principal de l'app.

┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 4 : POUSSER SUR GITHUB (1 minute)                                      │
└──────────────────────────────────────────────────────────────────────────────┘

  Dans votre terminal (dans le dossier du projet) :

    $ git add .
    $ git commit -m "Initial commit: Gaudí Walking App"
    $ git push origin main

  Attendez quelques secondes... 
  Rafraîchissez votre GitHub : vos fichiers doivent y être ! ✅

┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 5 : DÉPLOYER SUR VERCEL (2 minutes) ⭐ LA MAGIE ARRIVE ICI             │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Allez sur https://vercel.com/dashboard
  2. Cliquez "Add New" → "Project"
  3. Cliquez "Import Git Repository"
  4. Sélectionnez votre repo "gaudi-walking-app"
  5. Cliquez "Deploy"

  ┌─────────────────────────────────────┐
  │ Deploying...                        │
  │                                     │
  │ ⏳ Installing dependencies...       │
  │ ⏳ Building your app...             │
  │ ⏳ Optimizing...                    │
  │ ✅ Deployed!                        │
  │                                     │
  │ Your URL:                           │
  │ https://gaudi-walking-app.ver...   │
  └─────────────────────────────────────┘

  ✨ VOILÀ ! Votre app est en ligne ! ✨

┌──────────────────────────────────────────────────────────────────────────────┐
│ DÉBOGAGE 🔧 (SI QUELQUE CHOSE NE MARCHE PAS)                               │
└──────────────────────────────────────────────────────────────────────────────┘

  ❌ "Cannot find module 'next'"
  ✅ Faites: npm install

  ❌ "Module 'lucide-react' not found"
  ✅ Faites: npm install lucide-react

  ❌ "app/page.js not found"
  ✅ Vérifiez que le fichier existe dans le dossier app/

  ❌ "Deployment failed"
  ✅ Consultez les logs Vercel pour le détail
  ✅ Vérifiez que package.json est à la racine

  ❌ "Build cancelled"
  ✅ Attendez quelques secondes et relancez depuis Vercel

  ❌ "L'app se charge mais est vide"
  ✅ Ouvrez F12 (Console)
  ✅ Cherchez les erreurs rouges
  ✅ Signalez le problème
